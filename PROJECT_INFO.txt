═══════════════════════════════════════════════════════════════════════════

Bagdja GPS Tracker adalah sistem tracking GPS lengkap dengan:
- Backend: Supabase (PostgreSQL + Edge Functions)
- Frontend: React + TypeScript + Vite
- Features: Authentication, Device Management, GPS Data Collection

🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════

1. Setup Supabase:
   - Create project at https://supabase.com
   - Run migration SQL in SQL Editor
   - Deploy edge function: supabase functions deploy gps-receiver

2. Setup Frontend:
   cd frontend
   npm install
   cp env-example.txt .env.local
   # Edit .env.local with your Supabase credentials
   npm run dev

3. Test:
   - Open http://localhost:5173
   - Register & Login
   - Create device
   - Test API with test-gps-api.sh

Detailed instructions: See QUICKSTART.md or SETUP_GUIDE.md

📡 API ENDPOINT
═══════════════════════════════════════════════════════════════════════════

POST /functions/v1/gps-receiver

Headers:
  avl: YOUR_DEVICE_AVL
  api-key: YOUR_DEVICE_API_KEY
  Content-Type: application/json

Body:
  {
    "lat": -6.200000,
    "lng": 106.816666,
    "date_time": 1697644800000
  }

Response: 200 OK
  {
    "success": true,
    "message": "GPS data received successfully",
    "data": { ... }
  }
